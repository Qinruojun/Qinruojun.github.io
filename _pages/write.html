Formatting guide

Type ## for a heading, **bold** for emphasis, or - for a list. Use the toolbar for links, images, tables, and code blocks.

Write inline math with $…$, or put $$ on separate lines for a display equation. Formatting appears in place as you write. The toolbar also lets you switch to rich text or Markdown source.

Drafts stay in this browser. Download a Markdown copy to keep a portable backup.

Connect GitHub

Publish directly to your own blog. Use a fine-grained personal access token for Qinruojun.github.io only, with Contents: Read and write.

Create a token on GitHub. Choose an expiration date. Paste it here, not into a chat.

The token is sent only to GitHub. Without this option it stays in memory and is forgotten when you leave this page. Disconnect GitHub clears this tab’s saved token.

Insert an image

Insert a formula

Enter LaTeX without the surrounding $ signs. The formula renders in your draft after insertion. Click it in the editor to edit its source.
